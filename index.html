01 · The basics

What is GitHub?

GitHub is a cloud-based platform that uses Git to store code, track every change and help people work on the same project together.

Store

Your project lives safely online, so it is never lost if your laptop breaks.

Track

Every change is saved with a note, so you can see what changed and go back.

Share

Teams work on the same files at once without overwriting each other.

Git vs GitHub

Git is a free tool on your computer that records every version of your files.

GitHub is a website that stores those Git projects online and adds teamwork tools on top.

They talk to each other with three everyday commands. Pick one to see what happens:

git push uploads the commits you saved on your computer to GitHub.

        05 · The toolbox
        
    More than code storage
    
        
    GitHub bundles the tools a team needs into one place. Pick a feature to see it in action.
    
      
    
      
    
        
    
          
          
          
          
          
        
    

        
    
          
    Plan the work
    Issues are to-do items: bugs to fix or ideas to try. Projects arrange them on a board so everyone can see who is doing what.
    • Assign tasks to teammates
    • Label them: bug, idea, docs
    • Track progress from To do to Done
    
          
    
            
    To do
    
            
    In progress
    
            
    Done
    
          
    
        
    

        
    
          
    Automate the boring parts
    GitHub Actions runs tasks automatically, such as testing your code every time someone pushes a change.
    • Catches mistakes in minutes
    • Builds and publishes your app
    • Free for public projects
    
          
    
            
     CI · run #127
    
            
      
          
      
        
      

        
      
          
      A free website from a repo
      GitHub Pages turns files in a repository into a live website. This very site is hosted with it.
      • Free hosting for portfolios and projects
      • Updates every time you push
      • Address like yourname.github.io
      
          
      
            
       yourname.github.io
      
            
      Press Deploy site to publish
      
          
      
        
      

        
      
          
      Code from any browser
      Codespaces opens a full code editor in your browser, already set up for the project. Nothing to install.
      • Works on any computer, even a library PC
      • Same tools as a desktop editor
      • Free monthly hours for personal accounts

      Stay safe automatically
      Dependabot watches the libraries your project uses. When one has a known security problem, it warns you and even opens a fix.
      • Alerts for unsafe libraries
      • Automatic update pull requests
      • Secret scanning stops leaked passwords

        06 · AI helper
        
      Meet GitHub Copilot
      
        
      Copilot is an AI assistant built into GitHub and your code editor. It can finish your code, answer questions about it, and even work on a task by itself.
      
      
      

      
      
        
      
          
          
          
        
      

        
      
          
      
            
      Write a comment saying what you want. Copilot guesses the code and shows it in grey. Accept it, or keep typing.
      
            
      
              
      grades.js
      
              
      1// average of a student's grades
2function average(grades) {
3  return grades.reduce((a, b) => a + b, 0)
4    / grades.length;
5}
      
            
      
          
      

          
      
            
      Ask a question in plain English. Copilot reads the open file and answers. Pick a question:
      
            
      
              
      Copilot Chat grades.js
      
              
      
                
      Hi! I can see grades.js. What would you like to know?
      
              
      
              
      
                
                
                
              
      
            
      
          
      

          
      
            
      Assign an issue to Copilot. It works in the background, then opens a pull request for a person to review.
      
            
      
              
      Average shows NaN when there are no grades #57opened by alast · bug
      
              
        
              
        Handle an empty grades list#58 · draft pull request by Copilot · waiting for your review
        
            
        
          
        
        
        
      
        

      
        More ways Copilot helps
        
      
        
        
        Code review
        Reviews a pull request and leaves comments, like an extra teammate.
        
        
        Pull request summaries
        Writes a clear description of what your changes do.
        
        
        Commit messages
        Suggests a short message describing each change you save.
        
        
        Terminal help
        Explains commands and suggests the right one for what you want to do.
        
        
        Security fixes
        Proposes fixes when GitHub finds a security problem in your code.
        
        
        Tests and explanations
        Writes tests for your code and explains parts you don't understand.
